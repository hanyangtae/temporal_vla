## Round 1 요지 (Codex 반론 10건)

핵심: "현 v2는 Gate 1 통과 불가 — fit–β 누수, 성립하지 않는 drawer settle, 무효한 null/종결
규칙을 고치지 않고 750판 평가로 넘어가면 결과를 판정할 수 없다."

1. **[치명] fit–β probe 분리가 코드상 미보장** — `make_fit_manifests.py`는 전 구간(ep0–59)
   층화 split이라 "fit=ep0–29, β=ep30–44" 주장과 모순. → pq3 전용 3-way manifest + 교집합 0
   assert + 주입 회귀 테스트 요구.
2. **[치명] drawer 3-phase 중 settle은 관측 불가능** — `joint_p≥0.95`가 성공 조건 자체라
   성공 즉시 종료 → settle activation 없음. 2-state(pre-open/opening) 정직 명명 또는 drawer
   gated 제거 요구. phase별 양 클래스 ≥3 episode 게이트, 부분-arm(identity 폴백 무음) 금지.
3. **[치명] 판정 규칙 무효** — primary contrast 불명, 다중성 미처리, pooled z가 paired 구조
   무시(기존 집계기는 독립 두-비율 SE). exact paired McNemar + Holm + "비재현" 선언은 paired Δ
   단측 95% CI 상한 < +0.16일 때만, 그 외 불확정. "80% 검출력" 문구 삭제.
4. **[매우 높음] scene 고정·SR 선발 무대에서 "COAST 재현" 불성립** — 명칭 격하 및 주장 한계
   명기 요구 (COAST는 매 rollout scene 랜덤).
5. **[매우 높음] β probe 선택 단위≠적용 단위** — per-scene global로 고른 β를 cross-scene·gated에
   이식 불가(‖M−I‖·노출시간 상이).
6. **[매우 높음] null 1회는 null 분포 아님 + 3 active arm에 비매칭** — record-pool에서 label
   permutation은 길이/dwell 미보존. β=0 sham이 배선 위약으로 더 직접적.
7. **[높음] 5-arm 과잉/각 비교 부족** — COAST 재현에 직접 대응하는 arm은 cross-scene global
   하나. 사다리식 원칙 위반.
8. **[높음] length·phase-dwell confound 미구체화** — episode-equal cov·early-window·
   dwell-matched offline sensitivity(무료) + 사전 표(길이/dwell/도달률/norm) 요구.
9. **[높음] host·instruction 선택 confound** — arm×host 균형 배정, 3-host canary, obj 선발은
   SR 아닌 빈도 기준.
10. **[높음] 코드 변경안 semantic contract·default 보존 부족** — capture_token_mode enum 고정,
    all-token은 distinct feature_kind, `--steering-token-select` default None(VL 기본 보존),
    3 생성자 모두 전달, `--alphas 0.1`로 충분(신규 옵션 불요). Gate A 테스트 목록(bitwise
    parity/raw 일치/β=0/전달/구·신 pkl) 제시.

## Round 2 요지 (수정안 재반론 — 해소 1,2,4,8,9,10 / 잔여 6건)

1. **[치명] gated_cross_scene은 "타이밍 축만" 격리하지 않음** — 행렬 내용·추정 표본·노출이 동시
   변경. → **"phase-conditioned operator regime" 명명**, matrix SHA·phase timeline·누적 개입량
   `Σβ‖M_t−I‖F` 로깅. 순수 timing 검정(동일 M_global을 phase에서만 적용)·phase→matrix shuffle은
   confirmatory로.
2. **[매우 높음] task-pooled phase fit의 scene/instruction×outcome confound** — phase×cell×label
   기여 표 + leave-one-scene-out M_phase 유사도 게이트, 미충족 시 해당 task H2/H3 전체 N/A
   (일부 cell만 탈락 금지).
3. **[매우 높음] Holm family와 핵심 주장 불일치** — H3(gated>perm)가 secondary면 "perm 무효∧
   gated 유효" 주장 불가. → **{H1,H2,H3}×{drawer,ppcc} 6개 primary Holm**, McNemar 단독(이중
   판정 금지), decision script 동결 + global-null FWER sim. "perm 무효" 단정은 equivalence
   margin 필요 → 미채택 시 "gated가 perm 대비 우월(H3)"까지만.
4. **[높음] β 이식 문제 절반 해소** — gated 음성엔 "부적절 β" 반론, 양성 H3는 dose 차이일 수
   있음. → "공통 β composite regime 비교"로 한정 + phase별 β‖M_phase−I‖F dose 대조.
5. **[높음] null은 H1 배선 진단으로만 한정** — gated 방향 특이성은 matched gated null로
   confirmatory(독립 seed)에서. 사후 null 추가 시 active 결과 재사용 금지.
6. **[높음] 3-way manifest 밖 보조 실험이 누수 경로** — 스모크/canary 전용 seed 예약, fit
   재료는 fit_pool만, Gate D 이후 manifest+pkl hash 동결, eval 직전 재검증 abort.
