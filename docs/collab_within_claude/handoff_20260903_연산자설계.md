## 0. 공통 notation (모든 수식이 이 정의를 공유)

**표현 (무엇을 읽고 쓰나)**

- `record` — 추론 1회. GR00T N1.5는 chunk 16-step을 예측하고 5 env-step만 실행 후
  재계획하므로, record 해상도 = env 5-step.
- `h ∈ R^1536` — GR00T N1.5 action head(DiT) **layer 12 residual stream**의 record당
  표현. 캡처 규약: 마지막 denoise call(4회 중 idx 3), 49개 토큰을 평균("all"). 토큰
  세그먼트 경계: state / future(토큰 1:33) / action — 세그먼트 변형 연산자는 이 경계로
  나눠 각 세그먼트 평균을 따로 쓴다.
- `k` (denoise idx) — action head는 가우시안 노이즈에서 4회 denoise로 chunk를 만든다.
  개입 시점 변형: last-call(k=3, 기본) vs step-0(k=0, 첫 call).
- `z ∈ R^16` — AE-16 잠재. 인코더: 전역 표준화 `(h − μ_g)/σ_g`(μ_g∈R^1536 전역 평균,
  σ_g 스칼라 std) → MLP 1536→256→256→16(GELU). grid v1 930판 재구성 학습(무라벨).
- `z̃ = z − c` — scene 앵커 `c ∈ R^16`(그 scene의 기준 record 평균 — 규약은 연산자별
  명기)를 뺀 scene-중심화 잠재.
- `φ(s_t) ∈ R^18` — 로봇 상태 특징: proprio 9(eef_pos_rel 3 + eef_quat_rel 4 +
  gripper_qpos 2) + 인접 record 차분 속도 9. scene별 z-score.

**통계량**

- 클래스 첨자 `c ∈ {s, f}` = 성공(succ) / 실패(fail) rollout의 record.
- `μ_c ∈ R^1536(또는 R^16)` — 클래스 c record 평균. `Σ_c` — 클래스 공분산.
- `R_c = E[h hᵀ]` — 클래스 c의 비중심 2차 모멘트 (conceptor 계열 전용).
- `N(z; μ, Σ)` — 다변량 정규 밀도. log N은 정규화 상수 `−(d/2)log 2π` **포함**
  (⚠ ood 임계와 스케일이 어긋났던 사고 이력 — 반드시 상수 포함 정의로 통일).

**개입 파라미터**

- `β ∈ [0,1]` — 개입 강도. β=1이 완전 교체(β>1은 오버슛 — 금지 판정).
- `α` — ⚠ 중의어. ① conceptor **aperture**(C_c 닫힌해의 α), ② SAFE detector 발화
  **임계**(α 0.05/0.1/0.2). 문맥으로 구분, 병기 시 "aperture α" / "SAFE α"로 쓸 것.
- `r̂, v, d̂ ∈ R^1536` — 단위 방향 벡터. `s ∈ R` — setpoint(방향 위 목표 좌표, 스칼라).

**개입 사슬 (gated 계열 공통)**

`SAFE 발화(α 임계) → [phase 조건] → 연산자 적용` — per-step(record마다 재평가,
latch 폐기). serve hook 위치 = `scripts/serve/steering_hooks.py` 계열이 등록하는
DiT block residual(L12) forward hook. rsN 계열만 예외(아래 §7 — hook이 아니라
denoise 노이즈 선택).

## 1. conceptor (COAST 재현) — 대조 soft-projection, 곱셈형

- fit: `C_c = R_c (R_c + α⁻² I)⁻¹` (aperture α; R_c는 전 시점·전 denoise pool)
- 대조: `C_steer = C_s ∧ ¬C_f = (C_s⁻¹ + (I − C_f)⁻¹ − I)⁻¹`
- 개입: `h′ = h · Mᵀ,  M = (1−β) I + β C_steer`
- **steer 지점**: DiT 선택 layer(grid search, 주로 L10~12) residual — **상시**(게이트
  없음), 전 record·매 denoise call, 49토큰 전부에 동일 M 곱. 성공 부분공간 밖 성분을
  일괄 감쇠.
- 판정: **null** (exp3 900+1800판, 위약·6-Holm). 기전: 두 클래스 주부분공간이 거의
  겹쳐(물리 재부호화 지배) C_steer≈0 퇴화 → M≈(1−β)I = 위약과 동일한 전방위 감쇠.

## 2. sconceptor — 순수 성공 수축

- fit: `C_s = R_s (R_s + α⁻² I)⁻¹` (aperture α=0.1, 대조항 없음 → 퇴화 면함)
- 개입: `h′ = h · [(1−β) I + β C_s]ᵀ`
- steer 지점: conceptor와 동일(상시 곱셈). future-only 변형 = future 세그먼트
  토큰(1:33)에만 적용.
- 판정: null~미미 (exp6/42 §6.2) — 수축되는 성분에 실패 정보가 없음.

## 3. varc — 분산비 가중 수축

- fit: `w_i = f(σ²_{f,i} / σ²_{s,i})` (좌표별 실패/성공 분산비 가중)
- 개입: `h′ = h · Mᵀ,  M = (1−β) I + β · diag(w)` — 실패에서 분산이 커지는 축만 감쇠
- steer 지점: 동일. 판정: null — 산포를 줄여도 행동 불변 (read≠write).

## 4. setM — setpoint형 mean-diff (좌표 당김)

**기본형** (exp4~, phase별 fit):

- fit: `r̂ = normalize(μ_f − μ_s)`, setpoint `s = μ_s · r̂` (성공 평균의 r̂ 좌표)
- 개입: `h′ = h − β [ (h · r̂) − s ] r̂` — h의 r̂-좌표 하나를 성공 좌표 s로 당김.
  나머지 1535차원 성분은 보존.
- **steer 지점**: DiT L12 residual, **SAFE 발화 후 등록 phase record만**(gated) 또는
  상시(permanent 변형). 세그먼트판은 세그먼트별 `r̂_seg`·토큰별 `s_tok`에
  `delta = β·mask_seg·((h_tok·r̂_seg) − s_tok)·r̂_seg` — mask는 0/1이 아니라
  **게인 승수**(future-only=[0,1,0], 위약 dose-match 스케일).
- ⚠ all-token 적용 시 eef 진동 실측 → future-only 병행 규약.

**instruction판 (v4sb/v4r — 대상 scene 성공 금지 계약)**:

- 방향: `v = normalize( mean_sc( μ_{s,sc} − μ_{f,sc} ) )` — 타 4 scene 각각의
  scene-내 클래스 평균차를 평균 (scene 잔차화 공간의 instruction 공통 방향과 동치;
  sc는 대상 아닌 scene 인덱스).
- setpoint(하이브리드): `s = μ_{f,tgt}·v + mean_sc( (μ_{s,sc} − μ_{f,sc})·v )` —
  대상 scene 실패 평균의 v-좌표 + 타 scene 평균 이동량. 대상 성공 0판에서도 성립.
- phase 라벨 2종: GT 라벨러(gt판) / k8 cluster(ck8판). 미등록 phase 발화 시
  reseed 대체 개입(v4r 라운드 규약).
- 판정: β{0.3~1.0} 스윕 전 라운드 null~위약급, β1.5는 파손 37~41%(오버슛, 무효 판정).

## 5. condg — 상태-조건부 대조 guidance (감산형, 3중 게이트)

- fit: 클래스별 릿지 회귀 `ĥ_c(s_t) = W_cᵀ φ(s_t)`,
  `W_c = (Φ_cᵀΦ_c + λI)⁻¹ Φ_cᵀ H_c`, `λ = 10⁻³ n_c` (n_c = 클래스 record 수;
  Φ_c, H_c = 클래스 c의 상태·활성화 행렬). h는 scene 성공-phase 평균으로 중심화.
- margin: `m = ‖h − ĥ_s(s_t)‖² − ‖h − ĥ_f(s_t)‖²` (양수 = 실패 예측에 가까움)
- 대조축: `d̂(s_t) = normalize( ĥ_f(s_t) − ĥ_s(s_t) )` — 상태의 함수인 실패↔성공 축
- 개입: `h′ = h − β · g(m) · ⟨h − ĥ_s(s_t), d̂(s_t)⟩ · d̂(s_t)` — 성공 예측 대비
  잔차의 실패방향 성분만 감산. g(m) = margin 게이트(실패 쪽일 때만 >0).
- **steer 지점**: DiT L12(step-0 sweep에선 task별 L4~15 재선정), [SAFE 발화 → 등록
  phase 재방문 → margin 게이트] 3중 통과 record만, last-call 또는 step-0(k=0).
- 판정: **null 최종 확정** — 구제 0/100+ (β{0.3,0.6,1.0}×{last,step-0}×layer 소진,
  검정력 있는 기각). read는 유일 생존(margin AUROC 0.78~0.86)·write 전멸. 기전(44 §7.3):
  개입은 궤적을 다른 basin으로 차는 인과력은 있으나 어느 basin인지 못 정함.
- ⚠ 수학 노트: m의 h-기울기 `∇_h m = 2(ĥ_f − ĥ_s)`는 **h와 무관한 상수 방향** —
  condg 점수는 guidance(기울기로 밀기)용으로 부적격, 순위(선별)용으로만 유효.

## 6. reseed (rs1 / ps_reseed) — 재샘플 1회 [baseline 연산자]

- 개입: SAFE 발화 record에서 denoise 초기 노이즈 `z₀ ~ N(0, I)`를 **다른 seed로
  재추첨** 1회 → 그 chunk 재생성·실행. per-step이므로 발화 지속 시 record마다 반복 =
  시간축 순차 재시도.
- steer 지점: activation 무수정 — **정책 자신의 확률성(분포-안 섭동)**.
- 판정: RoboCasa 게이트+재추첨 = **+7.7%(구제 5/발화 65셀) — 유일 양성**. 단 SIMPLER
  순수 재샘플+외부 verifier(CoVer)는 음성(−2.8/−0.7) → "재샘플 이득은 게이트·선별
  신호의 질에 좌우" 병기 필수. 시간축 재시도는 구제 가능 셀을 거의 포화(5/6)시키는
  강한 baseline.

## 7. rsN_llr — 재샘플 best-of-N + 내부 LLR 선별 [현행 확정 연산자]

**철학 전환**: h를 고쳐 쓰지 않는다(§1~5 전멸). 정책이 합법적으로 가진 유일한
자유도(denoise 노이즈)를 N개 굴리고, read로 **고르기만** 한다. RL critic과 동형
(성공확률 critic) — 단 학습 없음·정책 내부 표현 위·scene 국소.

- 채점 공간: 후보의 h → AE-16 인코딩 → scene 앵커 감산 → `z̃ ∈ R^16`.
- fit(phase별·클래스별 가우시안): `μ_c ∈ R^16`, `Σ_c ∈ R^{16×16}`
  (로드 시 정칙화 `Σ_c + 10⁻³·tr(Σ_c)/16 · I`).
- 점수: `LLR(z̃) = log N(z̃; μ_f, Σ_f) − log N(z̃; μ_s, Σ_s)`
  = [성공 타원 기준 마할라노비스²/2 − 실패 타원 기준 마할라노비스²/2 + 타원 부피
  보정]. **양수 = 실패스러움**. 후보 점수 = chunk 내 record LLR 평균.
- 개입 절차: SAFE 발화 record에서 노이즈 `z₀⁽¹⁾..z₀⁽ᴺ⁾`(N=8) 배치 denoise → 후보별
  h 캡처·채점 → **argmin 실행**. entry 배정 = 후보 z̃와 각 등록 entry(scene×cluster
  phase)의 succ_mean 최근접 (현재 cluster가 아니라 **후보가 갈 곳** 기준 — "read의
  거처 ≠ 발화의 거처" 판정의 귀결).
- OOD 비관 규칙: `max(log N_s, log N_f) < ood_lo` 인 후보 기각. `ood_lo` = 대상
  scene 실패 rollout **후반절반**(발화 구간 대리) record의 max(logN) 5퍼센타일 —
  fit-창 기준으로 잡으면 발화 지역이 전원 기각되는 사고 이력(분포 격리 + logpdf
  상수항 스케일 버그 이중 원인).
- 등록 게이트: scene-내 CV AUROC 절대 기준(중앙값 ≥0.70 + 5-seed 과반 ≥0.65).
  ⚠ "LLR > 길이단독" 기준은 채점기 용도에 **범주 오류** — best-of-N 후보들은 같은
  시점 분기라 경과 길이가 동일, 길이는 후보를 순위 매길 수 없다. 미등록 = identity.
- steer 지점: **activation 무수정**. serve 2차 pass에서 N배 forward(발화 record당
  ~0.4s), fallback(미등록/전원 OOD) = 후보 0 = reseed와 동일.
- 상태: v4r 본 eval 완주 대기 중(60판 × [setm_gt 5β + setm_ck8 5β + rsn_llr +
  reseed]). 존재 증명 기준 = rsn_llr이 reseed에 더하는 것(예산 곡선·비구제 전환
  ×3 재현·FP 파손 비회귀).

## 8. 위약(placebo) 규약 — 전 연산자 공통

- 라벨 순열: succ/fail 라벨을 episode 단위로 섞어 동일 절차 fit (`*_pl`).
- dose-match: 위약의 실이동량을 처치와 세그먼트별 게인으로 정확히 맞춤 (setM seg_mask).
- N-매칭: rsN에선 rsN_rand(N개 중 무작위 선택) ≡ rs1 (수학적 동치 — 배선 sanity로만).
- 판정 원칙: **처치 vs 위약**만이 인과. 게이트·재현성 검증은 위약도 자기-통과한다.

작업장의 약간의 변화)에 맞춰 **scene 안에서** 만든다.

### 11.1 데이터 계약 (사용자 확정)

- 연산자 단위 = **(instruction, scene, 대상 k)** 하나 — scene 내 leave-one-k-out.
- fit pool = 그 scene의 **타 k 전판**(succ+fail) + **대상 k 실패판만**.
  대상 k 성공판은 fit·앵커·게이트·ood 전부에서 제외 = success-blind
  ("성공 가능한 k라면 구제 가능하다"는 주장의 조건절이지 운용 장치가 아니다).
- setM setpoint는 **기본형 `s = μ_s·v`** 로 회귀 — pool 성공이 같은 scene이라
  v4sb 하이브리드 setpoint의 존재 이유(scene 도메인 offset)가 소멸.
- 구현 = `scripts/analysis/grid_phase/rsn_llr/loko_fit.py` (버전 중립: `--tag`·`--coord`·
  `--axis-col`). 산출 per-지터 폴더층 `instr_setm_<tag>_{gt,ck8}/<slug>/s<i>/<coord><r>/`,
  `rsn_llr_reg_<tag>[_all]/<slug>/s<i>/<coord><r>.npz` + 같은 위치 `registry.tsv`.
  **v6 기본값** = tag `v6`, coord `j`, 좌표 열 `jitter_idx`.
  ⚠ v6 의 `jitter_reset_idx` 는 좌표가 아니라 출처 열(oven/washer 전부 0) — 좌표로 읽으면
  지터가 뭉갠다. 자동 선택에서 제외했고 고유값 1개면 즉시 중단한다.

### 11.2 성립 가능성은 index만으로 미리 갈린다

`loko_feasibility.py` (activation 불요): 대상 k-셀 31개 중 **26 가능 / 5 불가**,
불가 24판 전부 **OvenRack/out s4** — scene 성공이 1판(k1)뿐이라 k1 대상일 땐 pool 성공
0, 나머지 k에선 1 ep(공분산·게이트 불성립). 연산자 없이 도는 arm이 되므로 본 eval에서
분리·각주 권고.

### 11.3 ★등록 게이트 — 위양성 결함 3건과 교정 (합성 대조로 검증)

옛 게이트(pool ep AUROC ≥0.70)를 그대로 썼다면 **노이즈로 만든 연산자가 등록**됐다.

| # | 결함 | 실측 근거 | 교정 |
|---|---|---|---|
| 1 | **k 혼입** — pool 성공이 타 k에서만 오므로 라벨이 k와 상관 | index만으로 잰 k 정체성 단독 AUROC 중앙값 **0.835** (marsh 0.99~1.00, jug 0.95~0.98) | 등록 기준 = succ·fail **공존 k 안의 쌍만** 센 k-계층화 concordance. pool·길이·k단독은 aux 병기 |
| 2 | **앵커 누수** — k-중심화 앵커를 held-out 포함해 계산 | 순수 노이즈에서 concordance **0.73**(AE-LLR)·**0.97**(raw mean-diff) | 앵커를 LOO 안에서 재계산 |
| 3 | **표본 착시** — 쌍 24개여도 실표본은 ep 10개(쌍은 종속) | NULL에서 5셀 중 **3셀 오등록**(0.71~0.75) | k 안 라벨 **순열검정** 2000회, p≤0.05 추가 |

교정 후 재검증: **NULL 0/5 등록**(p 0.065~0.529) · **SIG 5/5 등록**(p 0.002~0.021).

부수 교정: 앵커를 **k-local**(cluster×k 평균)로. pool 평균 하나로 중심화하면 가우시안이
k 오프셋을 학습해 소수 클래스 episode를 **역순**으로 매긴다(합성 concordance 0.00).
번들의 `succ_mean`에는 **대상 k 앵커**(대상 k 실패 record 평균)를 실어 serve가 빼는 값과
일치시킨다.

**왜 k-matched가 옳은가**: 이 채점기는 *같은 episode·같은 시점*에서 갈라진 best-of-N
후보의 순위를 매긴다 — 후보들의 k는 전부 동일하므로 k를 읽는 성분은 순위에 기여할 수
없다. "길이는 후보를 순위 매길 수 없다"(§7)와 **같은 범주 오류**다.

### 11.4 열린 쟁점 — cluster 조건화가 대조를 흡수한다

합성에서 phase(cluster) 조건화 시 concordance가 **전체 0.93 → 클러스터별 0.50~0.63**
으로 떨어졌다. cluster를 LLR과 **같은 AE-16 공간**에서 나누기 때문에 조건화가 클래스
차이를 상당 부분 흡수한다(합성은 outcome 오프셋에 phase 구조가 없는 최악 조건이라
과대평가일 수 있다 — v4 실데이터에서는 per-cluster 0.82였다).
→ `--phase-mode all`(phase 조건화 없는 단일 entry `s<i>__call`, 산출 루트
`rsn_llr_reg_v5_all`, serve·NPZ 계약 동일)을 넣어 **rsn_llr(ck8) vs rsn_llr_all** 두 arm
실측 비교로 가린다. 최종 arm 구성은 중추·사용자 판단.
