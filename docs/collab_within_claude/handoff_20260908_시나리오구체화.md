## 2. 45 문서의 조항별 현재 상태 (§ 번호 = 문서 내)

- **§1 시나리오 정의**: 상황=(task, 배포지, 물건 집합) fit-노출 허용 / 재발 변주 축 =
  물건 배치 지터 + 정책 확률성 (로봇 초기 자세 축은 v4 실측으로 **폐기** — base pos가
  ep_meta에 고정, 관절 지터 mm~cm). **분모 정본 = base-replay 재정박** (수집 라벨 아님 —
  v4 라벨 반전 ~55~59% 실측). 게이팅 정본은 47 문서(per-step, latch 폐기).
- **§2 요구 일반화**: detector(per-task, phase-gt 절제 학습, FPR 상한) / 연산자(상황 내
  보간만, scene 암기 합격). cross-task 불요의 방어 근거 = 43 LOTO chance.
- **§3 검증 프로토콜**: episode 축 held-out, arm 표준(base/online/위약/**timer-gated 필수**/
  ablation), 셀-paired + 분모 명시 + 비회귀 조항, 자동 등록 게이트(min8/15딱지),
  최소 로그 **~100판**(병목=성공 희소, 성공<10이면 CP band 퇴화).
- **§4 수집 설계**: 문서에는 v2 제안+v3 필요로 남아 있으나 **실제 역사는 v4(폐기)→v5
  (legacy)→v6가 정본** — 현행 격자 규약은 `handoff_20260903_grid_v6_scene_jitter.md` +
  docs/04 §3.1.1 (`s<sid>/j<jid>/n<nid>`, 12키×3scene×5j×n10 확대 plan 77e745c37b0f).
  §4는 역사 문서로 두되 인수자가 v6 좌표로 갱신할 것 (아래 미결 1).
- **§4b 벤치마크 2단**: 주=RoboCasa 제약 프로토콜(정당화 3항) / 부=SimplerEnv (주류 검증
  08-18: GR00T N1.6 Bridge 56.6%/N1.7(Cosmos-Reason2 백본) 62.3%, 공식 ckpt 존재,
  RL² 정면 비교 무대). **부 실험은 미착수**.
- **§5 baseline·경쟁**: 판매 문장("잘하는 VLA의 저SR task를 ~100판으로 재학습 없이 국소
  수리해 ΔSR"), finetune 대조=최종 관문(ΔSR+forgetting, rs 양성 후 필수), 재샘플 대조=
  "타이밍 정보 우위"(감지-후 vs 상시; 라벨-순열 위약 정의 불가), rs 포지션 가드(순수
  best-of-N은 V-GPS·RoboMonkey·RL²-Repeated 기존재 — 기여는 "게이트된 best-of-N + 내부
  표현 verifier"), 죽은 주장 목록(multitask unseen 전이·일반 안전 모니터).

## 5. 미결 큐 (인수자 우선순위 순)

1. **45 §4를 v6 좌표로 개정** — v2/v3 서술은 역사가 됐고, 현행 격자(v6 scene·jitter
   3축)와 §1 재발 변주 축의 대응을 명시해야 함. 참고: v6에서 j축(reset/base 오프셋)이
   "배치 지터"의 구현체.
2. **rs_steer(게이트된 best-of-N + LLR verifier) 채점 수신 대기** — 45 기준 ①~④.
   최신(09-08, v6-holdout-detector-round 메모리): detector 무편향화 시 발화 18→30·구제
   전 arm 하락, setM≈reseed 수렴(0.17 vs 0.15) — "detector 편향이 구제율을 부풀렸나"가
   새 채점 쟁점. 채점표가 오면 §5 "현재 상태" 갱신.
3. **timer-gated arm 미실행** — §3 arm 표준에 있으나 아직 아무 라운드도 안 돌림.
   detector 조기성 가치 주장 전 필수 (43 세션 리스크 ②).
4. **finetune(LoRA) 대조 미착수** — rs 양성 확정 후 최종 관문. ΔSR + forgetting 축.
5. **SimplerEnv 부 실험 미착수** — 진입 비용 최소 경로: GR00T 공식 SimplerEnv ckpt +
   기존 serve 인프라. RL² 재현 이력은 docs/steering/38.
6. **margin 자가평가 캡처 진단 (이월)** — 개입 후 margin이 실제로 내려갔는지 1–2판
   활성화 캡처로 확인 (write 실패가 활성화 수준인지 행동 번역 수준인지). exp6에 이관해
   두었으나 실행 확인 안 됨.
7. **용어 규약**: 계획·보고 단위는 **instruction** (slug는 경로용 파생명 — 09-04 반려
   전례). 45에 남은 "task 단위" 표현을 instruction으로 정리할 때 이 규약 적용.
