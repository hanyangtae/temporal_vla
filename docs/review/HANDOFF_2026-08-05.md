## 2. 저장 규약 — 좌표 전환 (이번 세션 최대 변경)

**규약 문서 §3.1~3.3 이 단일 출처.** 구 `activations/<sig>/` 평면은 폐기.

```
<store>/groot/n15/grid/<plan_id>/<machine>/<instruction>/s<i>/n<j>/
    base/              rollout.pkl  traj.csv  video.mp4  meta.json
    <armsig>__<hint>/  traj.csv  video.mp4  meta.json  config.json
```

- **식별 = 좌표**(실행 전 확정 → `plan.missing()` 이 결손 반환), **무결성 = sig**(meta.json)
- `plan_id` = `CollectionPlan` 전체 해시(모델·ckpt·capture_layers·denoise_k·token_mode·그리드)
- **`machine` 은 `plan_id` 에 넣지 않는다** — 한 계획을 여러 머신에 나눠 돌리는 게 정상 운영

### 근거 실측 (2026-08-05, serve 9개)

| 비교 | bitwise |
|---|---|
| kanu A4000 GPU 0 vs 1 vs 3 | **일치** (max\|Δ\|=0) |
| srv50 A100 GPU 0 내 인스턴스 3개 · GPU 0 vs 1 | **일치** |
| **kanu vs srv50** | **불일치** — hidden 18,432 중 17,063개(93%) 상이 |

→ **GPU 는 좌표에 안 넣는다**(한 칸을 여러 GPU 에 병렬 배정 가능).
→ **base·arm 은 반드시 같은 머신**(paired 판정에 머신 효과가 섞이면 12.7% 판정 반전).

## 3. 코드 배선 (완료분)

`src/collect/plan.py` — **경로·지문 단일 출처**

| 함수 | 역할 |
|---|---|
| `GridCell.rel_path(plan_id, machine)` | 좌표 경로 조립 |
| `resolve_grid(args)` | 계획 로드 + 좌표 역산. 결손 → `(None,None)`, 범위 밖 → `ValueError` |
| `grid_dir_for(args, plan, cell, machine)` | 좌표 + arm → 최종 디렉토리 |
| `add_grid_args(parser)` | 공용 CLI 인자 6개 |
| `arm_signature(params)` | armsig 8자. `ARM_PARAM_KEYS` 7개 전량 요구 |
| `arm_dirname(armsig, hint)` | `<armsig>__<hint>` |

`write_safe_triplet` — **`grid_dir` 필수**(없으면 RuntimeError, §8). 4파일 세트 + `meta.json`
(sig·pkl_sha256·좌표·machine·ckpt·캡처 밀도 5열). §2 쓰기 검사(없음→쓰기 / 동일→skip / 상이→에러).

수집기 둘 다 배선 완료: n15 `http_feature_collect.py`, n16 `collect_rollout.py`.
