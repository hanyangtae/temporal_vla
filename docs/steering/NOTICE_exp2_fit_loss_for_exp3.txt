■ exp3 세션이 지금 해야 할 일 (중요)
1. **exp3 fit 실물 아카이브 상태 점검**: 승준 datasets의 phase_event_6p/raw_rollouts에
   exp3 새 cell들(ppcs_apple_s100106, s100172, ...)의 디렉토리가 "빈 채로" 이미 존재한다
   (07-16 확인). 즉 exp3 fit 실물이 로컬에만 있을 가능성이 높다 → 지금 실물 기준으로
   아카이브하고 검증하라 (아래 3번 기준).
2. **심링크 서브셋 만들지 말 것 / 상대경로로**: fit 서브셋(ps/xa/gx, Pool)을 심링크로 만들면
   같은 사고가 재발한다. 반드시 상대경로 심링크(§2.4-7) + 아카이브 rsync는 -L(--copy-links)
   또는 실물 복사.
   ⚠️ 컨테이너-호환 검증은 컨테이너를 만들거나 재시작하지 말 것 (수집기·VNC 세션 끊김 사고 방지).
   호스트에서 target 문자열 검사만으로 충분하다:
     find <dir> -type l -exec readlink {} \; | grep -vE "^/temporal_vla|^[^/]"
     → 출력이 있으면 그 링크는 컨테이너에서 깨진다 (절대경로가 /temporal_vla 밖).
   기존 컨테이너가 떠 있으면 read-only 확인도 가능: docker exec robocasa test -e <경로>
   (rm -f/재기동/마운트 변경 절대 불필요).
3. **삭제 전 보존 검증 표준 (이름 세기 금지)**:
   - find -type f 로 실물만 셀 것 (심링크 제외)
   - du 용량 대조 (원본 vs 아카이브)
   - 평균 파일크기 상식 체크: fit activation pkl은 개당 수십MB. 평균 ~1MB가 나오면
     껍데기/축소본을 세고 있는 것 — 즉시 중단하고 조사.
4. exp2 fit raw를 참조하는 분석(예: denoise 축 대조를 exp2 cell로 하려던 계획)이 있으면
   → 재생성 필요 여부를 사용자와 결정 후 진행.
