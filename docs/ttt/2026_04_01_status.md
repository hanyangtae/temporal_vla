## 아직 논문과 다른 부분 (미결)

### ❗ 핵심 train/test mismatch: Window 학습 vs Full Trajectory 학습

**현재 구현 (window 기반)**:
```
에피소드 → 8프레임 window 잘라냄 → 독립적 학습 샘플
TTT 메모리 축적: 8프레임 안에서만
```

**VITA 논문 (full trajectory 기반)**:
```
에피소드 전체 (T ≤ 120프레임, padding) → 배치 구성
TTT 메모리 축적: θ_0 → θ_1 → ... → θ_T (전체 T프레임 순차)
ℓpred 계산: dissimilarity sampling으로 선택된 window들만
```

논문의 "implicit memory" 효과가 학습 중에도 발생해야 하는데, 현재는 추론 때만 발생.
"We use a batch size of 32 and pad all trajectories to a maximum length of 120 frames" (Appendix D.1)

**구현하려면 필요한 변경:**
1. Dataset: episode 단위 샘플 반환 (full trajectory, padded to 120)
2. Forward pass: full T프레임 TTT 순차처리 + selected windows에만 ℓpred
3. Training: step 기반 → epoch 기반 (5 epochs ≈ 2986/32 × 5 ≈ 470 steps)

**난이도**: 중간 (dataset + forward 재작성 필요)
**우선순위**: 재학습 결과 보고 판단

### step 수
- 논문: 5 epochs over full trajectories ≈ **~470 gradient steps**
- 현재: 100,000 steps (≈ 134 epochs over window dataset, 과학습)
- 재학습 시 권장: `--total_steps 20000` 정도로 시작, val loss 보며 early stop

## 다음 단계 (Phase 2 준비)

Phase 2는 Phase 1 체크포인트 기반으로:
- TTTModule + ProgressHead **freeze**
- VLAProjector만 학습 (4가지 주입 모드: hidden_add, logit_shift, film, token)
- Loss: `-Δv · log P(a_expert | s_t, θ_t + injection)`
- Δv = v(s_{t+1}) - v(s_t)

```python
# 시작점
from src.ttt.predictor import ProgressPredictor
predictor = ProgressPredictor(...)
predictor.load_state_dict(torch.load("<cache>/checkpoints/phase1/step_0050000.pt"))
predictor.save_init()
predictor.freeze_for_phase2()  # TTT + Head freeze, VLAProjector만 학습
```
