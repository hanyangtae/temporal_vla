# Weekly — 주간 정리

Notion `Weekly Report`에 올리는 주간 보고의 **로컬 원본**. 사람이 읽는 경과 기록이고,
근거·수치·재현법은 기술 문서에 두고 **링크만** 한다.

## 기술 문서와의 역할 분리

|  | 기술 문서 (`docs/steering/*` 등) | 여기 (`docs/weekly/*`) |
|---|---|---|
| 목적 | 근거·재현 | 보고·경과 |
| 수명 | 사실이 바뀌면 갱신 | **그 주로 고정**, 나중에 안 고침 |
| 내용 | 수치·함정·재현 절차 | 무엇을 왜 했고 결론이 뭔지 |
| 독자 | 다음 세션·에이전트 | 사람 (교수님·본인) |

> **수치를 여기 복붙하지 않는다.** 헤드라인 한두 개만 남기고 나머지는 기술 문서 링크로.
> 그래야 수치가 정정될 때 고칠 곳이 하나다. (이번 세션에도 seed median↔최댓값,
> layer 12↔15 같은 정정이 여러 번 나왔다.)

## 파일 규칙

- 파일명 = **그 주 월요일 날짜** `YYYY-MM-DD.md`. 정렬이 되고 "몇째주" 논쟁이 없다.
- 문서 첫 줄에 Notion 주차 표기(`8월 2째주`)를 병기해 Notion과 대응시킨다.
- 템플릿: [`TEMPLATE.md`](TEMPLATE.md)
- 보고를 건너뛴 주는 **파일을 만들지 않는다** (Notion도 건너뛴 주가 흔함).

## 작성 흐름

1. `/weekly-report` 스킬이 git log·docs·memory·outputs를 모아 **이 폴더에 초안**을 쓴다
2. 사용자 검토·수정
3. Notion 해당 주차 toggle에 업로드
4. 파일 하단 `## 링크`에 Notion URL 추가 → 다음 주 Recap 소스가 된다
