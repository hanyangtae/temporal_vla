읽는 법

  • x축 기본 = inference step(저장된 0-based decision 번호, 칸 1개 = decision 1회); 토글로 env step 보기. decision 1회마다 chunk 16 예측 중 5 env step 실행; 마지막 chunk는 m<5일 수 있음(성공 시 성공 chunk 끝까지). 시간(초) 추정은 하지 않음.
  • basic = chunk 내 실행 step의 할인 기본보상 R. MIX = R + α·(anchor − Φ) − β·C (α=0.1, β=0.0396).
  • α항 = α·(anchor − Φ): Φ 차이에 γ^m·bootstrap 없음. anchor = 다음 decision의 Φ, 마지막(terminal) 행은 outcome anchor(성공 +1 / 실패 −1).
  • −βC = 실제 차감량(부호 포함). C = max(0, −Φ)·Σi<m 0.99i. Δ = MIX − basic = α항 + (−βC).
  • Φ는 저장된 배열을 그대로 표시. cluster ID는 미저장이며 Φ로부터 역추론하지 않음.
  • 같은 rollout은 target j가 다른 여러 fold의 fit 세트에 중복 포함됨: basic은 동일, MIX는 fold별 potential이라 다를 수 있음.
